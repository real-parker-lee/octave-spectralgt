# octave-spectralgt
This package adds some utility functions to GNU Octave related to spectral graph theory.

# Install
In your shell, run:
```bash
git clone https://github.com/real-parker-lee/octave-spectralgt.git
tar -czvf octave-spectralgt.tar.gz octave-spectralgt
```
Then, in Octave, navigate to the folder in which the package was built, and run:
```
pkg install octave-spectralgt.tar.gz
pkg load octave-spectralgt
```

If you're not using a POSIX-compatible OS (like Windows), download the package from the releases tab.
